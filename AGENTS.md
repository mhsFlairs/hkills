# Repository skills

Reusable skill packages live in `skills/`. See [README.md](README.md) for the catalog and installation commands. Preserve each skill's supporting resources when updating or installing it.

- [codex-efficient-subagents](skills/codex-efficient-subagents/SKILL.md): Use for cost-aware Codex delegation, including trivial and routine bounded execution. Keep the current main agent; consider parent/Sol planning followed by Terra execution for mixed-complexity work. Prefer Luna for bounded Git, transcription, PowerShell, and search/evidence workflows; use stronger reasoning for large or complex merges and unresolved decisions. Workers check in with the parent on material ambiguity, blocked access, scope changes, or capability limits; parents respond and manage safe reassignment. Follow the skill's delegation-first rules, limited fallback conditions, and acceptance checks.
